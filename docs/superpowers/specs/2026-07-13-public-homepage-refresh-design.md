# 遇见路得公开首页焕新设计

## 目标

把根路径 `/` 从功能演示墙改为遇见路得的正式品牌首页。首页只完成三件事：让访客理解产品服务谁、为什么值得信任、如何进入 `/app/` 开始真实流程。

## 设计方向

- 以 SALT 的信仰气质和 Hinge 的克制叙事为参考，不照搬品牌元素。
- 首屏直接展示“遇见路得”品牌名，配一句面向认真婚姻关系的明确主张。
- 使用现有真实产品截图作为首屏媒体和产品展示，避免虚构用户、虚构统计与假匹配结果。
- 色彩使用墨绿、暖白、珊瑚红与少量亮黄，避免紫色渐变、玻璃拟态和单一米色调。
- 页面采用完整内容带和留白，不使用卡片墙；圆角不超过 8px。

## 页面结构

1. 顶部导航：品牌、理念、流程、成长、登录、开始使用。
2. 首屏：品牌名、产品主张、双 CTA、真实产品媒体。
3. 品牌横向文字轨道：认真、真实、预备、同行。
4. 核心差异：资料完整、共同成长、关系确认三个无卡片步骤。
5. 产品实景：展示当前登录界面，并说明应用内四个主空间。
6. 关系旅程：完善、预备、认识、确立四阶段。
7. 最终 CTA 与简洁页脚。

## 交互与可访问性

- 动效限制为首屏入场、文字轨道、滚动显现三类，并尊重 `prefers-reduced-motion`。
- 移动端使用可展开导航，360px 宽度不横向溢出。
- 所有 CTA 指向真实 `/app/` 或 `/app/register` 路由。
- 保留跳转主内容链接、语义标题层级、键盘焦点和按钮状态。

## 验收

- 根路径不再出现资料表单、假搜索、假候选、套餐或假统计。
- 首屏在桌面和手机都能看见品牌、主张、主 CTA，并露出下一段内容。
- `/app/` 入口可用，应用区路由不受影响。
- 控制台无错误，页面无重叠和横向滚动。
