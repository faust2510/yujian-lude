# 遇见路得 Figma 推特式生产 UI 设计规格

日期：2026-07-19

## 决策与优先级

本规格取代 `2026-07-18-social-app-ui-redesign-design.md` 中“去特定平台化”的视觉限制。登录后的 `/app/` 必须以 Figma 文件 `遇见路得 UI 设计系统` 的 `02 Desktop`、`03 Mobile` 与本地原始导出包为唯一视觉基准，采用可识别的推特式三栏社交产品骨架。旧版后台式页面、宽仪表盘卡片和旧 CSS 不能作为视觉参考。

Figma 文件：`https://www.figma.com/design/nvWK0aiQ0PRSHQJq64AfvT`

原始设计包：`/Users/qwe/.codex/visualizations/2026/07/18/019f73b5-c6d1-7621-b6b5-6138decb5c1c/meet-ruth-ui/`

## 范围

重建登录后 8 个桌面核心页面：

- 首页 / 此刻
- 认识 / 每日精选
- 成长
- 社区 / 同行
- 消息 / 书信
- 我的资料
- 路得 AI
- 会员与积分

移动端必须覆盖首页、认识、消息、路得 AI、会员与积分，并让其他已登录路由使用同一移动外壳。官网根路径、登录、注册、找回密码不在本次视觉替换范围内。

## 视觉系统

- 桌面画板：`1440×1024`。
- 桌面三栏：左栏 `236px`、主区 `900px`、右栏 `304px`。
- 主区页头 `112px`，内容区 `912px`。
- 移动画板：`390×844`，顶部 `70px`、内容 `700px`、底栏 `74px`。
- 品牌色：`#6E1F35`；深色：`#471321`；浅色：`#F1E4E8`、`#F7EFF2`。
- 古金：`#A8864A`；浅金：`#F8F3E8`。
- 背景：`#F8F4EB`；纸面：`#FCFAF5`；白色：`#FFFFFF`；银白：`#F7F8F9`。
- 正文：`#251F22`、`#5F555A`、`#81777B`；边框：`#DED8D5`。
- 标题使用中文衬线体，正文和控件使用中文无衬线体。
- 卡片使用 1px 柔和边框、14px 圆角和 `0 2px 8px rgba(37,31,34,.06)` 阴影。
- 图标使用与 Figma 一致的 Lucide 风格线性 SVG。

## 共享外壳

桌面左栏固定展示品牌、首页/认识/成长/社区/消息五个一级入口，底部展示当前用户与资料完成度。主区包含品牌 eyebrow、页面标题、副文案、页签和内容。右栏根据路由展示人物、小组、关系预备、AI 额度、公平说明或安全提示。

移动端隐藏桌面左右栏，显示 70px 页头和固定五项底部导航。底栏不能遮挡页面主要操作，内容不得横向溢出。

## 页面内容

- 首页：关系罗盘、预备进度、动态流、今日值得认识、值得关注的小组。
- 认识：候选卡、匹配比例、审核状态、匹配理由、心动/跳过/私信与安全说明。
- 成长：继续课程、关系练习、AI 引导与学习回顾。
- 社区：关注/小组/话题页签、现有帖子流、互动与小组推荐。
- 消息：桌面会话列表和线程双栏；移动端先显示会话列表。
- 资料：验证状态、个人简介、价值标签、预备进度和敏感信息说明。
- AI：深酒红额度 hero、输入区、建议提示、最近咨询和边界说明。
- 会员：公平承诺、免费/成长/同行三档、积分余额和兑换入口。

## 业务边界

现有 API、认证、权限、隐私、匹配资格、双方心动后私信、社区权限和表单提交逻辑保持不变。UI 不得伪造成功状态。会员只影响 AI/成长权益，不能影响匹配或曝光排序。

## 验收

1. 1440px 截图中三栏宽度、页面层级、颜色、字体、卡片和按钮与 `desktop.png` 一致。
2. 390px 截图中移动页头、内容密度、底栏和核心操作与 `mobile.png` 一致。
3. 8 个桌面核心路由均使用同一外壳；不存在旧版后台侧栏或旧珊瑚色主题残留。
4. 现有前端测试、lint 和构建通过。
5. 生产服务器运行的提交、`web-dist` 资源文件名与本地发布记录一致。
6. 生产 `/app/` 登录后的实际截图完成 Figma 对照后，才可宣布完成。
