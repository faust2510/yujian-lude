# 遇见路得公开首页 Rose Editorial 重设计

## 目标

将公开首页从偏理性、偏工具化的深绿方案，改为具有当代爱情品牌气质的 Rose Editorial 落地页。页面应在第一眼呈现浪漫、真诚和年轻感，同时保留遇见路得对信仰、婚姻预备与关系边界的郑重态度。

本轮只重做公开首页 `/`，不修改 `/app/` 的业务流程、后端 API 或数据库。新的色彩、字体和媒体语言将作为后续应用区视觉迁移的参考，但不在本轮扩散到应用区。

## 页面类型

- 类型：品牌落地页。
- 核心任务：建立品牌印象，说明产品差异，引导访客进入 `/app/register`。
- 首屏不是搜索工具、资料表单或功能演示，不呈现虚构统计、虚构用户与虚构成功故事。

## 视觉方向

采用 **Rose Editorial**：以现代时装编辑感表达浪漫，而不是使用婚庆影楼、少女滤镜或传统相亲网站语言。

关键特征：

1. 大面积浅玫瑰粉与珍珠白，深酒红承载正文，樱桃红只用于主 CTA 和关键强调。
2. 使用真实人物纪实影像，人物状态自然、克制、有生活感，不使用摆拍婚纱照、拥吻特写或模糊氛围图。
3. 图案使用细线花体、双人关系轨迹和手写式强调线，不使用漂浮爱心、粒子雨、花瓣雨或卡通贴纸。
4. 中文品牌标题使用现代宋体，正文与操作使用清晰黑体；避免整页古典宋体造成教会宣传册感。
5. 页面以完整内容带、图文节奏和留白组织，不使用满屏圆角卡片。

## 媒体策略

首屏必须使用一张横向真实人物照片作为全宽背景媒体，文字直接覆盖在媒体上，不放进卡片。照片选择标准：

- 东亚成年男女，自然相处或并肩行走的纪实场景。
- 面部和关系状态可辨认，光线明亮，不使用暗、糊、过度裁切的氛围素材。
- 画面保留一侧安静区域承载品牌文字。
- 素材必须可合法用于产品页面并保存为项目本地资源，不依赖运行时外链。

第二张媒体用于“认识与成长”段落，展示真实互动而不是婚礼结果。第三处产品媒体使用脱敏后的真实应用截图，帮助访客理解这不是只有故事的宣传页。

## 布局结构

### 顶部导航

- 纸张白背景，品牌在左，三个锚点导航居中，登录和“开始使用”在右。
- 不使用模糊、半透明或玻璃效果。
- 手机端保留品牌、主 CTA 和菜单图标，展开后使用完整纸张白页面。

### 首屏

- H1 必须是“遇见路得”。
- 支撑文案：“在信仰里，认真靠近一个真实的人。”
- 一个樱桃红主 CTA“开始遇见”，一个低强调文本入口“了解我们”。
- 全宽人物媒体作为背景，通过实体色遮罩保证文字可读，不使用渐变遮罩。
- 首屏高度约 74–80svh，所有桌面和手机视口都要露出下一段的粉色关系轨迹带。

### 品牌轨迹带

- 使用连续细线和文字轨道表达“认真预备 · 真实认识 · 清楚确认 · 在信仰里同行”。
- 轨迹不是卡片，不使用图标堆叠。

### 核心差异

- 标题：“不是认识更多人，而是更认真地认识一个人。”
- 三个无卡片栏目：预备自己、真实档案、清楚确认。
- 使用樱桃红、酒红与薄荷灰三条不同结构线区分，但不把每栏做成独立彩色卡片。

### 认识与成长

- 全宽薄荷灰内容带，真实人物媒体占主视觉，文字覆盖或与媒体错位排布，但不使用左右各一张卡的结构。
- 说明课程、教材、社区和关系流程如何共同服务真实认识。

### 产品实景

- 纸张白背景，展示脱敏应用截图与四个主空间。
- 截图使用不超过 8px 圆角，允许一个实体色偏移阴影，不放进额外卡片。

### 关系旅程

- 四步：完善、预备、认识、确立。
- 使用连续关系线连接四步，桌面横排、手机纵排。
- 不使用四张重复卡片。

### 品牌寄语与最终 CTA

- 路得记 1:16 作为独立编辑式引用段落，避免教会海报式装饰。
- 最终 CTA 使用酒红背景与樱桃红按钮，页面只有这一处大面积深色。

## 图案系统

图案由三类元素组成：

1. **关系线**：两条细线从不同方向进入，在关键段落交汇后继续前行。
2. **花体轮廓**：使用单线弧形构成抽象花瓣，只出现在段落边缘，不围住正文。
3. **手写强调**：关键词下方使用轻微不规则的樱桃红线，不使用黄色荧光笔效果。

图案必须是次级信息，透明度和密度受控，不得压过真人媒体、标题或 CTA。

## 动效

全页只保留三类动效：

1. **首屏入场**：标题、正文和 CTA 依次上移 12–18px 并显现，总时长不超过 700ms。
2. **关系轨迹**：滚动进入相应段落时，细线从 0 绘制到完整长度；每条线只播放一次。
3. **媒体轻移**：真人媒体随滚动发生 2–4% 的缓慢位移或缩放，不自动循环。

文字轨道可做低速连续横移，但它与关系轨迹共享同一动效预算，最终实现时二选一。所有动效尊重 `prefers-reduced-motion`，关闭动效后内容必须完整可见。

## 响应式与可访问性

- 支持 360px、390px、768px、1440px 及宽屏桌面。
- 不按视口宽度连续缩放字体，使用明确断点和 `clamp()` 只控制区间。
- 手机首屏 CTA 可换行但不截断，品牌名不得被菜单或媒体覆盖。
- 所有正文、按钮和焦点状态满足 WCAG AA 对比度。
- 菜单打开后可滚动、焦点受控，横竖屏切换自动解除页面锁定。
- 无 JavaScript 时正文保持可见，图片提供准确替代文本。

## 不做

- 不使用紫色或粉紫渐变。
- 不使用玻璃拟态、模糊导航和发光边缘。
- 不使用爱心雨、花瓣雨、漂浮粒子和自动播放轮播。
- 不使用登录表单或应用截图作为首屏主视觉。
- 不使用假统计、假评价、假情侣故事和假匹配卡。
- 不在本轮重构 `/app/` 内页。

## 测试与验收

1. 静态结构测试锁定品牌标题、真实 `/app/` CTA、关键区块和禁用元素。
2. 自动检查公开资源不包含邮箱、手机号等敏感信息。
3. 浏览器验证 1440×900、390×844、360×800 与 667×320 横屏。
4. 检查首屏下一段露出、图片裁切、文字换行、横向溢出、菜单焦点和横竖屏切换。
5. 控制台无错误，所有资源返回 200；禁用动效和禁用 JavaScript 时内容仍可阅读。

## 完成标准

访客在第一屏能明确感受到这是一个浪漫但郑重的爱情婚恋品牌；粉色成为品牌主基调但不幼稚；真实人物媒体和关系线图案共同建立情绪；页面只保留一个明确主行动；进入 `/app/` 的真实路径可用；桌面与手机均无重叠、溢出和不可访问状态。
